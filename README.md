# Лабораторная работа №1: Перемножение матриц

Программа на C++ для перемножения двух квадратных матриц с автоматической верификацией результатов через Python (NumPy).

## Характеристики вычислительной системы
* **Процессор (CPU):** 13th Gen Intel(R) Core(TM) i5-13420H
* **Операционная система:** Microsoft Windows 10 Pro x64 (версия 10.0.19045)
* **Среда разработки:** Visual Studio / CMake (конфигурация `x64-Release`)
* **Компилятор C++:** MSVC (стандарт C++20)
* **Среда верификации:** Python 3.12 (библиотека NumPy)
